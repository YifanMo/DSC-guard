# DSC-Guard Artifact Snapshot

This repository contains a lightweight artifact snapshot for the DSC-Guard paper draft.

## Contents

- `artifacts/log_trace/`: materialized replay traces for the six evaluated incidents.
- `artifacts/slither_ir/`: Slither-derived semantic IR used by the replay pipeline.
- `artifacts/k/`: generated K-style replay semantics (`.k`) and compile manifest.
- `artifacts/evaluation/`: RQ metric summaries, ablation results, lead-time results, and benign evaluation summaries.
- `artifacts/eval_dataset/`: positive case manifest and compact 10,000-row benign evaluation manifests.
- `artifacts/paper_tables/`: CSV/JSON tables used by the paper.
- `results/`: generated reports for case evidence, dataset audit, and RQ summaries.
- `scripts/`: collection, materialization, replay, evaluation, and table/figure rendering scripts.
- `paper/jss_dsc_guard/`: current JSS manuscript draft and generated figures.

## Excluded Large Evidence Caches

The local project also contains raw RPC/explorer request caches, raw receipt aggregates, source caches, and debug traces. Those files are intentionally excluded from this Git snapshot because they are large and can be regenerated by the scripts with the configured API keys. The published snapshot keeps compact manifests and replay/evaluation outputs needed to inspect the reported results.

## Reproduction Entry Points

```bash
python3 scripts/reproduce_mvp.py --mode verify
python3 scripts/run_dsc_guard_experiments.py --rq rq1,rq2,rq3,rq4
python3 scripts/render_paper_tables.py
python3 scripts/render_jss_experiment_figures.py
```

All scripts are read-only unless explicitly passed rebuild or RPC-fill options. API keys are not included.
